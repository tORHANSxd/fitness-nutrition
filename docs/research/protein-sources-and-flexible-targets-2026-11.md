# 蛋白质来源与灵活营养目标

核验日期：2026-11-06。面向一般成人抗阻训练与日常营养记账；定向检索，不是系统综述。产品采用总量、食物来源和实际训练表现的联合检查，不加入逐项氨基酸计算。

## 更适合日常配餐的方法

**总蛋白按食品原克数累计，主要来源单独查看。** 谷物、豆类、坚果等都计入；一种来源的必需氨基酸比例偏低，不代表这些蛋白全部多余。逐食物乘一个质量分数再相加，会漏掉整份饮食的互补，也不能得到可靠的“增肌有效克数”。[FAO，2013，第4节](https://www.fao.org/4/i3124e/i3124e.pdf)

在这个原则下，配餐按以下顺序核对：

1. 先满足确认的全天蛋白目标，克数中包括全部食物。研究中的每公斤蛋白摄入通常指全饮食总量。
2. 查看各类食物贡献了多少蛋白，以及每餐的实际蛋白量。正餐安排乳、蛋、鱼、肉、大豆制品等主要蛋白来源；以植物为主时重视豆类、谷物等来源搭配。这是配餐指导，不设置未经验证的“优质蛋白必须占60%”门槛。
3. 胶原、明胶按原值计入蛋白和热量，但不把它们当成与乳清等可按同克数互换的主要增肌来源。
4. 结合总热量、训练表现、体重趋势与恢复复核目标。不因“植物来源”自动加20%蛋白，也不固定打八折；缺乏能支持这种通用系数的长期人体结果。

| 证据 | 能支持什么 | 不能推出什么 |
| --- | --- | --- |
| [Hevia-Larraín 等，2021；PMID 33599941](https://pubmed.ncbi.nlm.nih.gov/33599941/) | 38名年轻男性，12周抗阻训练；全饮食约1.6 g/kg/天，纯植物加大豆与杂食加乳清均有改善，未检出组间差异。 | 按原有饮食分组，非饮食来源随机试验；不能证明所有食物等效，也未验证统一植物加量系数。 |
| [Reid-McCann 等，2025；PMID 39813010](https://pmc.ncbi.nlm.nih.gov/articles/PMC12166177/) | 43项RCT，30项肌肉量合并；总体小幅偏向动物来源，大豆与乳蛋白未检出差异。 | 混合人群与干预不能化成逐食物折扣；无显著差异不等于严格等效。 |
| [Askow 等，2025；PMID 40197715](https://pubmed.ncbi.nlm.nih.gov/40197715/) | 40名年轻成人、9天控制饮食，来源及分布组间每日肌原纤维蛋白合成未检出差异。 | 维持热量下的短期合成指标，不能证明减脂期长期增肌等效，或每餐分布永远无影响。 |
| [IMPACT，2026；PMID 42772454](https://pubmed.ncbi.nlm.nih.gov/42772454/) | 108名55岁以上成人，12周训练；蛋奶素与杂食组都改善，但素食组蛋白约1.24、杂食组1.58 g/kg/天，未证实附肢肌量非劣效。 | 蛋白总量并未匹配，不能把差异全归因于来源，更不能据此规定年轻训练者的食物折扣。 |
| [Oikawa 等，2020；PMID 31919527](https://pubmed.ncbi.nlm.nih.gov/31919527/) | 22名老年女性、6天；乳清对肌肉蛋白合成的作用优于胶原。 | 不是长期肌肉量试验，不能说胶原完全无用。 |

## 碳水、脂肪和热量的特殊口径

| 项目 | 计算器处理 |
| --- | --- |
| 纤维 | 已知量按可食克重汇总；未知显示部分合计。来源总碳水、可利用碳水分别保留，不统一重复扣纤维。 |
| 糖醇、阿洛酮糖 | 因子取决于具体物质及来源规则；有原始标签能量时沿用，缺种类和含量时不猜净碳水或额外减热量。 |
| 抗性淀粉 | 可能与纤维重叠，不能再次扣除；不给冷饭、冷面统一“减卡百分比”。 |
| GI | 表示相对血糖反应，不能乘到碳水克数或热量上充当吸收率。 |
| 饱和、反式脂肪及必需脂肪酸 | 属于总脂肪中的组成；健康意义单独解释，不折扣克数、不另罚热量。缺资料不记零。 |
| 食物热效应 | 不从常规食物能量中再次扣除；不能把净代谢能与通常TDEE口径混用。 |

依据：[USDA 数据定义](https://fdc.nal.usda.gov/Foundation_Foods_Documentation/)、[FAO 能量换算第4章](https://www.fao.org/4/y5022e/y5022e05.htm)、[FAO 食物热效应与需求口径](https://www.fao.org/4/Y5022E/y5022e04.htm)、[FDA 阿洛酮糖说明](https://www.fda.gov/food/food-additives-petitions/sugars-are-metabolized-differently-traditional-sugars)、[美国标签能量因子](https://www.ecfr.gov/current/title-21/chapter-I/subchapter-B/part-101/subpart-A/section-101.9)、[FAO GI定义](https://www.fao.org/4/W8079E/w8079e0a.htm)。这些来源用于解释各自口径，不把美国法规因子强加给中国食品。

## 目标输入与保存规则

“我已有目标”支持固定热量、维持热量减固定缺口，以及三大营养素固定克数推导热量。蛋白、脂肪、碳水分别可选择固定克数、全体重倍数、去脂体重倍数或剩余热量。去脂体重来自同日体重与体脂，或明确输入的直接去脂体重。

- 克数 = 所选体重 × 系数。最多一项使用剩余热量；蛋白、碳水除以4，脂肪除以9。
- 三项都指定时必须与目标能量一致；超预算拒绝，不把剩余项截成零掩盖错误。
- 新自定义策略使用 `nutrition-goals-v5.1` / `nutrition-v5.1`，保留小数，不自动凑整或补脂肪底线。旧 v5.0 方案、默认场景和个人标准继续按原算法复算。
- 当天可直接填写摄入热量，也可填写维持热量与缺口；固定摄入不要求编造TDEE。宏量规则与身体输入放在该日 `dailyEnergyAdjustment.macroInputs` 中，实际记录保存同一覆盖；最新体测不重算冻结的当天输入。
- 当天覆盖使用现有计划/实际原子事务、revision及所有权检查，取消后恢复本日基础目标。新日期不继承临时覆盖，食物克重不随目标变化。

数据库迁移 `20261106013925_flexible_macro_targets.sql` 必须先于新客户端发布。它新增精确宏量求解并扩展已有校验器，不修改历史迁移或用户数据。V3文档封装、协议表、RPC参数和食物快照无需升级。
